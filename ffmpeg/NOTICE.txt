Official downloads/source: https://ffmpeg.org/download.html
Provider/build scripts: https://github.com/GyanD/codexffmpeg
License: GPLv3, see GPL-3.0.txt in this directory.

AussieTV runs ffmpeg.exe as a separate child process; it does not link against
FFmpeg libraries. The portable Windows release should carry this notice, the
upstream build information, and the relevant GPL files. Distributor(s) must
also meet the complete-corresponding-source requirements of the GPL license.

If the binary is not present in this directory, run SETUP-FFmpeg.cmd in a
Windows build folder to download and SHA-256-verify the upstream distribution.
The executable can also be supplied using AUSSIETV_FFMPEG_PATH (absolute path)
or via the normal system PATH.
