# Pre-beta development history

AussieTV was iterated in private/prototype builds using labels `v1.0` through
`v1.9` and `v2.0` through `v2.0.9`. Those names described **development
milestones**, not semver-stable releases. The first labelled beta is
**v0.1.0-beta.1**, 18 November 2026.

The repository's `versions/v1.*` branches and GitHub releases titled
`(historical)` are retained so that previous work and reports stay traceable.
They must not be represented as supported downloads. The active install
instructions and downloads are exclusively in the root README and latest
`v0.x` GitHub prerelease.

Historical progression: TV guide and channel playback; remote navigation;
channel logos and programme artwork; caption/Teletext prototype; Windows
tray and Settings; firewall and authenticated Jellyfin M3U/XMLTV; experimental
HDHomeRun discovery, HLS relay and FFmpeg MPEG-TS remuxing.

Known unresolved bugs are listed in [Beta known issues](BETA-KNOWN-ISSUES.md).
Older `CHANGELOG.md` and `README.txt` versions included contradictory settings
and out-of-date playback guidance; those were replaced with current beta docs.
