TV remote controls

 
Use a remote that sends keyboard commands through HDMI-CEC, USB, Bluetooth, a TV browser or a compatible remote-control bridge. Navigate the complete interface without a mouse.

 

  
Arrows / D-pad
Move within each row or section; at an edge continue into the neighbouring section

  
OK / Enter
Activate an item; on dropdowns OK starts editing, OK again applies

  
Back / Escape
Close an overlay, exit fullscreen, return to the guide

  
CH +/- / Page Up/Down
Switch to the previous or next channel

  
Numbers 0–9
Enter a channel number, then wait a moment to tune

  
G / M / H
Go to guide / browse networks / show help

  
C / T / F
Captions / text information / fullscreen

  
Media play/pause
Toggle playback when supported by the browser

 
Some smart-TV browsers reserve the Home, Back, number or coloured remote keys. Only keys delivered to the page can be handled. Browser support for live HLS video also varies.
